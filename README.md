# AsymmetryTPC — Моделирование режимов трёхфазной цепи

Учебный проект по курсу «Электричество и магнетизм». Математическое моделирование установившихся режимов трёхфазной электрической цепи с асинхронным двигателем методом симметричных составляющих.

За основу взята методика из статьи Г. П. Карабашева [«Моделирование режимов трёхфазной цепи с поперечной несимметрией»](https://openedu.rea.ru/jour/article/view/40/42) (*Открытое образование*, № 3, 2015).

---

## Цели и структура проекта

Проект разделён на две части:

1. **Теоретическая подготовка и расчёты**:
   - постановка задачи и допущения модели;
   - вывод матричной системы уравнений методом симметричных составляющих и методом эквивалентного генератора;
   - подбор параметров реального оборудования;
   - контрольный аналитический и матричный расчёт симметричного режима.
2. **Программная реализация на Python и визуализация**:
   - реализация комплексного решателя на базе `numpy.linalg.solve`;
   - построение векторных диаграмм токов и напряжений;
   - расширение модели на режимы поперечной несимметрии.
